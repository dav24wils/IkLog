# IkLog
IkLog is a nice in-code logging utility class meant to give developers total control as to how logs are acquired and where they are saved, devs now don't need to rely entirely on the android's inbuilt Log class for everything since it is difficult to sometimes find where your favorite ide displays logs. The good news is that logs are stored in the public Download directory, plus this utility class also logs details to the logcat using android's Log class internally to ensure that you did not miss the use of the official logcat at all.
